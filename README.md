# Superior Support Living — Website

## Pages
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `contact.html` — Contact
- `privacy.html` — Privacy Policy
- `style.css` — Shared stylesheet

## Deployment
This site is auto-deployed to Netlify on every push to `main`.
